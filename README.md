# Portfolio

My personal portfolio site. Live at https://zndionisio.pages.dev.

## Stack

- Astro
- Tailwind CSS

## Commands

```sh
npm install
npm run dev      # dev server, port 4321
npm run build    # static build to dist/
npm run preview  # serve dist/
```

## Structure

```
src/
├── pages/index.astro
├── components/
├── data/
│   ├── projects.ts
│   └── skills.ts
├── images/
└── styles/global.css
```
